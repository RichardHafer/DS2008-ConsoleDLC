# Dead Space 2008 Randomizer: Console DLC 1.0.2

Changes since 1.0.1:

- Fix recoloured RIG stasis bars showing health instead of remaining stasis. The shader now recognizes the renamed stasis materials used by the coloured suits.
- Check the retail instruction bytes before installing the fix. The log reports whether the hook installed and when a recoloured bar first draws with the stasis value.

The suits, prototype weapons, textures and shipped colour settings are unchanged from 1.0.1.

## Update

Close the game and extract the archive into the folder containing `Dead Space.exe`. Keep your existing settings if customized. Existing recoloured suit copies do not need to be deleted.

Made for the Steam build 1.0.0.222. Runs on its own or with Randomizer 1.0.2 or later; Randomizer 1.0.4 adds the public F9 weapon and suit menu. When both plugins are installed, use the randomizer's INI and log.

Before uninstalling the DLC, equip a regular suit at a store and save in a new slot. A save wearing a DLC suit still needs the add-on.
